# Security Layer Demo Attack Pack

This directory contains six demo attack payloads used to validate the security layer end-to-end in a lightweight test harness.

## Included attacks

1. `prompt_injection_tool_call.md`
2. `opencode_secret_read_attempt.md`
3. `mcp_scope_bypass_attempt.json`
4. `retrieval_unauthorized_doc_attempt.json`
5. `artifact_secret_leak_attempt.html`
6. `sandbox_unsafe_config.env`

Each attack file includes scenario context and expected outcomes for policy decision, audit logging, findings, and launch-gate/report evidence where applicable.
